# 2\. Application \+ S3







## Objective:

```
Deploy a small application on EC2 which allows a user to upload a file.
The uploaded file should go to an S3 bucket, and some basic information about the file can be stored in a database.
Please make sure the application accesses S3 through an IAM role rather than storing AWS access keys on the server.
Also look at:
S3 encryption
Bucket permissions
IAM permissions
Versioning
Lifecycle policy
Show the complete flow during the demo.
```

## Infrastructure Setup:

### 1. S3 Bucket

**Region**: Asia Pacific (Mumbai) ap-south-1

**Name**: file-upload-demo-bucket-342524208531-ap-south-1-an

**Block *****all***** public access** on - for securing access via IAM role only

**Encryption:** Enable SSE-S3 (AES-256) 

 **Bucket Key**: Enable   - `When KMS encryption is used to encrypt new objects in this bucket, the bucket key reduces encryption costs by lowering calls to AWS KMS`

**Bucket Versioning**: Enabled

**Lifecycle Policy:** Create rule: Move to Standard-IA after 30 days -\> Glacier after 90 days -\> Expire noncurrent versions after 180 days

**Bucket Policy:** No public access. Only allow access via specific IAM Role.


### 2. IAM Role 

Name: `EC2-S3-Upload-Role`

Trust Relationship: `ec2.amazonaws.com`

Only read/write access allowed to the EC2 instance of the bucket - file-upload-demo-bucket-342524208531-ap-south-1-an

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:PutObject", "s3:GetObject", "s3:ListBucket"],
      "Resource": [
        "arn:aws:s3:::file-upload-demo-YOUR_ROLLNO",
        "arn:aws:s3:::file-upload-demo-YOUR_ROLLNO/"
      ]
    },
    {
      "Effect": "Allow",
      "Action": ["dynamodb:PutItem", "dynamodb:Scan", "dynamodb:GetItem"],
      "Resource": "arn:aws:dynamodb:ap-south-1::table/FileMetadata"
    }
  ]
}
```


### 3. DynamoDB Table 

- **Table name:** `FileMetadata`
- **Partition key:** `file_id`
- **Data type:** `String` 
- **Sort key:** blank
- **Table class:** `DynamoDB Standard`\[default\]
- **Read/write capacity settings:**
    - Selected **On-demand** - This is best for demo, no need to provision capacity.
- **Encryption at rest:** `AWS owned key` - It's enabled by default. This satisfies your encryption requirement for DB. 
- **Point-in-time recovery (PITR):** Leave OFF for demo to save cost.
- **Tags:** Optional - Add `Project: S3-Upload-Demo`
- We don't need to pre-create columns. DynamoDB is schema less.

### 4. EC2 with attached role


1. Name: `s3-upload-server`
2. AMI: **Ubuntu Server 22.04 LTS**
3. Instance type: `t2.micro`
4. Key pair: Create new / use existing
5. **Network:** Default VPC is fine. Auto-assign public IP: **Enable**
6. **Security Group:** Create new
    - Rule 1: SSH - Port 22 - My IP
    - Rule 2: Custom TCP - Port 5000 - 0.0.0.0/0 (for testing)
    - Rule 3: HTTP - Port 80 - 0.0.0.0/0 (for final demo)
7. **Advanced Details \> IAM instance profile:** Select your Role `EC2-S3-Upload-Role` - **This is most important**

**app.py**

```py
import boto3
import os
import uuid
from datetime import datetime
from flask import Flask, request, render_template, redirect, url_for, flash
from werkzeug.utils import secure_filename
from botocore.exceptions import ClientError

app = Flask(__name__)
app.secret_key = os.urandom(24)

# --- CONFIG - Change these ---
S3_BUCKET = "file-upload-demo-YOUR_ROLLNO" # Replace with your bucket
DYNAMODB_TABLE = "FileMetadata"
AWS_REGION = "ap-south-1"

# boto3 will automatically use EC2 IAM Role credentials
# No aws_access_key_id needed
s3_client = boto3.client('s3', region_name=AWS_REGION)
dynamodb = boto3.resource('dynamodb', region_name=AWS_REGION)
table = dynamodb.Table(DYNAMODB_TABLE)

ALLOWED_EXTENSIONS = {'txt', 'pdf', 'png', 'jpg', 'jpeg', 'zip'}

def allowed_file(filename):
    return '.' in filename and filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

@app.route('/', methods=['GET', 'POST'])
def upload_file():
    if request.method == 'POST':
        if 'file' not in request.files:
            flash('No file part')
            return redirect(request.url)

        file = request.files['file']
        if file.filename == '':
            flash('No selected file')
            return redirect(request.url)

        if file and allowed_file(file.filename):
            original_filename = secure_filename(file.filename)
            file_id = str(uuid.uuid4())
            s3_key = f"uploads/{file_id}_{original_filename}"

            try:
                # 1. Upload to S3 - via IAM Role
                # Encryption is enforced by bucket settings (SSE-S3/SSE-KMS)
                s3_client.upload_fileobj(
                    file,
                    S3_BUCKET,
                    s3_key,
                    ExtraArgs={
                        'ContentType': file.content_type,
                        'ServerSideEncryption': 'AES256' # or 'aws:kms'
                    }
                )

                # 2. Get file size - we need to reset pointer
                file.seek(0, os.SEEK_END)
                file_size = file.tell()
                file.seek(0)

                # 3. Store metadata in DynamoDB
                table.put_item(
                    Item={
                        'file_id': file_id,
                        'file_name': original_filename,
                        's3_key': s3_key,
                        's3_bucket': S3_BUCKET,
                        'file_size_bytes': file_size,
                        'content_type': file.content_type,
                        'upload_timestamp': datetime.utcnow().isoformat(),
                        'uploader_ip': request.remote_addr
                    }
                )

                flash(f'Success! File {original_filename} uploaded to S3 and metadata saved.')
                return redirect(url_for('list_files'))

            except ClientError as e:
                flash(f'AWS Error: {e}')
                return redirect(request.url)

    return render_template('index.html')

@app.route('/files')
def list_files():
    try:
        response = table.scan(Limit=20)
        items = response.get('Items', [])
        # Sort by latest
        items.sort(key=lambda x: x.get('upload_timestamp', ''), reverse=True)
        return render_template('files.html', files=items)
    except ClientError as e:
        return f"Error fetching from DynamoDB: {e}"

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```
